=== Changed

* *Breaking for existing installs:* ten packages are re-registered under
fresh UUIDv8 identifiers, each at a patch bump: `+HardwareResilience+`,
`+SiliconCore+`, `+ZeroProb+`, `+QuantumCircuit+`, `+ShellIntegration+`,
`+FirmwareAudit+`, `+ViperPkg+` and `+LowLevel+` at `+0.1.1+`;
`+Causals+` and `+SMTLib+` at `+0.2.1+`. Their old UUIDs were hand-typed
placeholders. A Manifest that pins one no longer resolves: run
`+Pkg.rm+` and then `+Pkg.add+` of the same name. ADR 0002 has the
old-to-new UUID table. `+ViperPkg+`'s repo URL moves to
`+hyperpolymath/jtv-lang+`.
* `+.github/workflows/governance.yml+` — SHA-pin the standards
governance reusable (was floating `+@main+`) (PR #17).
* `+.github/workflows/scorecard.yml+` — job-level
`+security-events: write+` + `+id-token: write+` permissions to match
the reusable’s canonical caller block; fixes `+startup_failure+`
regression introduced in PR #17 (PR #19).
* Consolidate `+CONTRIBUTING.md+` and `+CONTRIBUTING.adoc+` into a
single canonical Markdown file (PR #19).

=== Removed

* Registry: `+InvestigativeJournalist v0.1.0+`
(`+379a7c0a-3675-4b32-b948-cb4760c6e442+`). Its dependencies named the
retired Causals and ZeroProb UUIDs. Use `+InvestigativeJournalism+`.
* Registry: every version registered under the ten retired placeholder
UUIDs (`+0.1.0+`, or `+0.2.0+` for Causals and SMTLib). Those versions'
own `+Project.toml+` files declare the old UUID, so they are not carried
across (ADR 0002).
* `+.machine_readable/STATE.a2ml+` (root) — moved to canonical
`+.machine_readable/6a2/STATE.a2ml+` per estate structural-drift policy
(PR #17).

=== Security

alerts as `+won't fix+`; root cause fixed at SARIF render layer in
https://github.com/hyperpolymath/hypatia/pull/368[hyperpolymath/hypatia#368].
* Closed seven real open code-scanning alerts via the four reusable
wrappers, `+codeql.yml@language=actions+`, and the STATE.a2ml move (PR
